Pi extension · Jev · observation not autobiography

pi-jev-assist

Checks an agent’s work against what was actually run and what the diff actually says. No slash command. Speaks when it has something; silent otherwise. Never edits your code, never certifies done, never starts a turn.

One session, every hook

Cost is Jev unless noted. Fail-open everywhere a missing daemon must not stop work.

session_start

Warm the code graph

Ensure a Vortex index and start a file watcher. Indexing a large repo takes minutes — doing it on the first write would stall the edit or silently degrade blast radius to text search. Fire-and-forget. Clears per-file speed bumps; re-bootstraps if cwd changed on resume/fork.

Off the critical path · no Jev
before_agent_start

Skill suggestions from the live catalogue

Scores the skills Pi is actually advertising this run — not a directory scan of the wrong folder. Suggests at most two above 0.90. Only name and path, never model-authored instructions. Catalogue over 128 skills: abstain explicitly rather than secretly shortlist.

1 Jev call
tool_call · write / edit

Pre-write blast radius

The only hook that runs before a change and can block. Names callers that depend on what the file exports. Speed bump, not a gate: once per file per session; re-issue the edit and it proceeds. Fails open. 12% of blocking review findings in 1,252 comments were unconsidered callers — a planning failure a post-diff check arrives too late to prevent.

Graph call, sub-second · no Jev
tool_result

Clip huge dumps

Results over 20k characters keep 6k head + 2k tail so a failure at the end of a test log still shows. Mechanical. Measured 0–29% of tool-result characters on real sessions.

None
tool_execution_*

Evidence ledger

Pairs calls with results by id. Redact before clip. Sensitive paths and credential-dumping commands withheld entirely. Bounded: 120 entries, 300-char commands, 1,200-char excerpts. isError is the only status Pi gives — the ledger never pretends a command “passed”.

None
context

Live prune

Same Jev questions as compaction, every turn after ≥8k of finished tool output — so later prefills shrink without waiting for /compact. Last 6 messages pinned. Fail-open. Live slice: 43% of judged tool text, 14% of a 40-message span.

agent_settled

Review vs ledger, claims vs diff, callers of what changed

Only when idle, clean stop, and there is something reviewable. Wrap-up prose with no check does not fire. Claims are checked against the working-tree diff, not against the assistant’s summary of itself. Callers only if files changed. Speaks only when there is a flag — chrome that prints every turn gets ignored.

≤3 Jev calls
session_before_compact

Verbatim compaction

Select, do not rewrite. Survivors are byte-for-byte; dropped output becomes a one-line note. Real 60-message span: 130,464 → 23,921 characters, 81.7% smaller, user constraints intact. Falls back to Pi’s summariser if saving <25%, Jev fails, split turn, or there is no tool output to prune.

What each feature is for

Skills, not the wrong folderPi’s live catalogue only. Disable-model-invocation honoured. Suggestion is metadata, not new instructions.
Blast radius before the editVortex call graph when present (transitive Calls, including callers that never mention the symbol). Ripgrep fallback that says it is textual.
Evidence, not autobiographyThe settled review reads the ledger. Your own summary of your own work scores well and proves nothing.
Claims vs the diffStructural claims discriminate. “Revokes poisoned payloads” scored 0.84 on a miss — absence is detection, where this fails. An overstated flag demotes a tick.
Context that does not paraphraseCompaction and live prune delete finished tool output. Paths, error strings, and constraints stay verbatim.
Hard limit, on purposeA diff shows what code says, never that it works. Tests remain the only authority on behaviour.
